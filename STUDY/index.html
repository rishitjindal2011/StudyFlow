How to install (like any professional app)

  1. Click Download for Windows — saves the installer (StudyFlow-Setup).
  2. Run the installer → choose folder → Install.
  3. Open StudyFlow from the desktop or Start menu.
  4. Start a focus session — Alt+Tab is blocked automatically. No Chrome extension needed.

Desktop app

Runs in its own window — not a browser tab. Fullscreen focus mode and PC-level Alt+Tab block.

Timer & stats

Pomodoro, custom modes, streaks, subjects, themes, and Flux AI study help.

Parental mode

Password-protected settings so students cannot disable blocks mid-session.

Also on the web

Use studyflow.html in Chrome with the extension for blocking other tabs.
